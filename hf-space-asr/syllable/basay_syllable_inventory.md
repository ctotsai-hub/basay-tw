# 巴賽語（Basay）音節目録

**対象語彙：** PAN（祖先語再建形）ソースを除く 2,364 エントリより抽出  
**収録音節：** 頻度2以上・`'`起始を除く 486 種  
**頻度凡例：** ★ 高（≥50回）／☆ 中（10–49回）／無印 低（2–9回）

---

## 正書法・IPA 対照表

| 正書法 | IPA | 説明 |
|--------|-----|------|
| `n'`   | ŋ     | 軟口蓋鼻音 |
| `s'`   | ʃ     | 硬口蓋歯茎摩擦音 |
| `l'`   | ɭ     | そり舌側面音 |
| `z'`   | ɮ     | 有声歯茎側面摩擦音 |
| `o'`   | ə     | 中舌中段母音（シュワー） |
| `'`    | ʔ     | 声門閉鎖音（前音節の韻尾として表記） |
| `q`    | q     | 口蓋垂／咽頭音（推定） |
| `ts`   | ts    | 歯茎破擦音 |
| `ts'`  | tʃ    | 硬口蓋歯茎破擦音 |
| `j`    | j～dʒ | 接近音または破擦音（文脈依存） |
| `v`    | v     | 有声唇歯摩擦音 |
